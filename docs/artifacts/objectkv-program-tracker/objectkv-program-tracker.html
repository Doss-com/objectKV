[01]Program call

Current decision

Retain the native read plane and complete the T27 cache curve

The corrected 64 MiB calibration cleared throughput, p99, CPU/read, semantic, and telemetry bounds in both orders. D60 retains T27 as Evaluating until fixture reuse, explicit page-cache treatment, and the 1 GiB coverage and skew sweep complete. FoundationDB remains the correctness oracle and fallback.

What has changed

The project separates execution, transaction durability, and permanent object state. The R0 mechanism reconstructs a complete resident image from regional GCS plus retained history, survives worker replacement, and performs zero object operations in measured reads. The first explicit cache budget exposed a forced tail SST and two probes per latest read. Keeping that disposable tail mutable brought the worst throughput, p99, and CPU/read gaps to 5.7%, 4.4%, and 5.9%. The next question is whether the same boundary holds across cache coverage, skew, and physical NVMe reads.
