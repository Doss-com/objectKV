Current architectural call

The kernel is not page-native

objectKV owns ordered keys, opaque value bytes, versions, transactions, and recovery. The first PostgreSQL adapter stores PostgreSQL pages as values so PostgreSQL keeps its existing semantics. Row-native PostgreSQL remains a separate future compute decision.
