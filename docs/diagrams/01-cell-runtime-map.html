What workers and services must run for one cell?

A cell is a bounded database cluster. The roles below are logical protocol boundaries. Cell v0 may colocate them in fewer binaries, but their authority and failure semantics stay separate.

EXISTS MECHANISMS
Naming decision. Use KV Runtime for the disposable RAM and NVMe process. A KV Runtime hosts many Range Engines. “Range server” remains a recognizable Bigtable and HBase term, but it is too narrow as the primary objectKV service name.
