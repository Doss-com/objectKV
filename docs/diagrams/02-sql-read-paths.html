How do OLTP and OLAP SQL reads stay fast?

DIAGRAM 2 OF 3

They share one commit and schema history, not one physical read path. Row-oriented access uses indexes, batched KV reads, and hot caches. Analytical access uses versioned columnar bases, durable change tails, and distributed scan execution.
