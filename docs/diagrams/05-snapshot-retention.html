Lease admission

02

Two frontiers

Logical expiry is not the same event as physical deletion.

Minimum readable FT < F → snapshot_expired

05

Serving result

Workers remain disposable and read bounds stay explicit.

Read in [F, C]floor check → applied check → MVCC seek

RAM and NVMe accelerate the path. Immutable objects plus the recent txLog rebuild it.

Read outside [F, C]T < F: expired · T > C: unavailable

The system returns a typed refusal. It never substitutes a nearby version.
