# Security policy

objectKV is pre-release and must not be used for production data.

Do not open a public issue for a suspected vulnerability. Report it privately to
the maintainers through GitHub's private vulnerability reporting for
`Doss-com/objectKV`. If that channel is unavailable during launch, contact the
repository owners directly.

Never include credentials, signed object URLs, customer data, private bucket
names, or unredacted production payloads in an issue, benchmark, trace, or
experiment ledger.
